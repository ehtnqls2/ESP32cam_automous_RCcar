# ESP32-CAM 기반 자율주행 RC카

## 프로젝트 개요
- **목적**: ESP32-CAM으로 실시간 영상을 스트리밍 받아, 차선 인식과 표지판(정지/서행/유턴) 인식을 결합해 스스로 주행하는 RC카 구현
- **구성**: ESP32-CAM(차량 제어 + 영상 송출) + PC(영상 수신 및 주행 판단, YOLOv5 추론)

## 사용 기술
- **HW**: ESP32-CAM, DC 모터 2개(좌/우), OLED 디스플레이(SSD1306)
- **SW**: Arduino(C++, ESP32 펌웨어), Python, OpenCV, PyTorch(YOLOv5), Multithreading

## 시스템 구조

```
[ESP32-CAM]                              [PC]
 ├─ 카메라 영상 → MJPEG 스트리밍 (포트 81)  →  OpenCV로 스트림 수신 및 디코딩
 ├─ HTTP 서버로 모터 제어 명령 수신 (포트 80) ←  차선/표지판 인식 결과에 따른 제어 명령 전송
 └─ OLED에 SSID/PW/IP 표시
```

### 1. ESP32-CAM (펌웨어)
- 부팅 시 EEPROM에 저장된 SSID가 없으면 `car` + 랜덤 숫자로 새 SSID를 생성해 Wi-Fi AP를 열고, OLED에 SSID/PW/IP를 표시
- `esp_http_server`로 두 개의 서버를 구동
  - 포트 80: `/action?go=<command>` 형태로 전진/후진/좌우 회전/속도 변경 명령을 받아 모터 제어
  - 포트 81: `/stream`으로 카메라 프레임을 MJPEG 스트리밍
- 모터 제어는 좌/우 각 2개 핀(H-bridge 방식)의 HIGH/LOW 조합과 PWM(`analogWrite`)으로 방향과 속도를 제어

### 2. PC (주행 판단)
- `urllib`로 ESP32-CAM의 MJPEG 스트림을 수신해 JPEG 프레임 단위로 디코딩
- **차선 추적**: 프레임 하단 영역을 색상 기반(HSV/RGB 임계값)으로 이진화해 검정 선을 추출하고, `cv2.moments`로 무게중심(cX)을 계산 → 무게중심과 이미지 중앙 사이의 offset에 따라 직진/좌회전/우회전 상태 결정
- **표지판 인식**: YOLOv5 커스텀 모델(`best.pt`)로 정지(stop)/서행(slow)/유턴(Uturn) 표지판을 감지해 속도 제어 및 정지·유턴 동작을 오버라이드
- 차선 추적 로직과 YOLO 추론을 각각 별도 스레드로 분리해, 무거운 추론 연산이 실시간 프레임 처리를 막지 않도록 구성

## 결과
- ESP32-CAM 영상 스트리밍만으로 무선 원격 주행 제어 구현
- 색상 기반 차선 추적과 YOLOv5 표지판 인식을 결합해, 표지판 규칙(정지/서행/유턴)을 반영한 자율주행 동작 확인


## 향후 개선 방향
- 조명 변화에 따른 색상 기반 차선 인식의 민감도 개선
- YOLO 추론 지연으로 인한 표지판 인식-제어 반응 시간 단축
